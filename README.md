CALMQUEST

CalmQuest is a therapeutic endless runner game designed specifically for children with ADHD (Attention Deficit Hyperactivity Disorder) and Autism Spectrum Disorder (ASD).

The game combines engaging gameplay with sensory-safe design principles to improve:

1.Focus and attention
2.Cognitive control
3.Emotional regulation

Unlike traditional fast-paced games, CalmQuest provides a calm, structured, and adaptive environment that reduces overstimulation while maintaining engagement.
